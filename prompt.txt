# SCROLL INSTRUCTION — ALL SECTIONS

Every section **except the final section** must contain a subtle scroll instruction at the bottom.

Use exactly:

### ↓

### Scroll down to see more

The instruction should:

* Be centered
* Use elegant typography
* Use gold
* Have a subtle glow
* Gently move up and down
* Fade in when the section becomes visible
* Fade out when the user starts scrolling
* Never behave like a button
* Never block content
* Never remain permanently distracting

The arrow can use a thin animated gold chevron.

The entire invitation must be a single HTML document:

```html

    <section id="welcome"></section>

    <section id="story"></section>

    <section id="details"></section>

    <section id="countdown"></section>

    <section id="bless"></section>

    <section id="final"></section>

</main>
```

Do NOT create:

```text

Page 2
Page 3
Page 4
```

Instead, create one continuous page containing seven full-screen sections.

# IMPORTANT — REMOVE THE OLD SCREEN SYSTEM

Do not use the existing fixed-screen architecture.

Remove the concept of:

```css
.screen {
    position: fixed;
    opacity: 0;
    visibility: hidden;
}
```

Do not use `.screen.active` to switch between sections.

Each section must remain in the document.

Use:

```css
.invitation-section {
    position: relative;
    width: 100%;
    min-height: 100svh;
}
```

Allow the browser to naturally scroll through the entire invitation.

# SCROLLING


The user must be able to continuously scroll from Opening all the way to Thank You.
